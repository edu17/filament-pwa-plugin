# Changelog

All notable changes to `filament-pwa-plugin` will be documented in this file.

## 1.0.0 - 2026-08-15

- Initial release with per-panel manifests, isolated service workers, safe offline fallback, configurable icons, and fluent panel overrides.
- Added an optional per-panel settings page with database persistence, panel- or Gate-based access, and automatic icon generation from one source image.
- Corrected panel scope boundaries so `/admin` controls both `/admin` and its nested routes.
